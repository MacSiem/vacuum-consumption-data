# Data attribution and licensing

Original database organization and contributor-owned measurements are offered under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

Attribute Vacuum Consumption Data, identify the dataset version, retain record-level provenance and indicate modifications. This does not change the license of any linked manufacturer manual, integration code or third-party API content. Publicly accessible does not imply freely redistributable: review upstream terms before distributing bulk protocol extracts. Only the public protocol ID/source/hash index is included in this repository. Full upstream descriptions are retained in local research and are excluded from the runtime bundle and public preparation.

Do not contribute data you are not entitled to share. No raw private Home Assistant Diagnostics, serial numbers, device IDs, room names, maps or tokens are accepted. Before initial public publication, confirm the data attribution inventory and remove material whose redistribution terms cannot be established.
